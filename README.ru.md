# MenuBench

[English](README.md) · **Русский**

Бенчмарк и эталонный конвейер разбора цен в меню ресторанов: фото, сканы, PDF.

> Неверная цена на экране хуже пустой рамки.

Поэтому конвейеру разрешено сказать «не уверен», и это входит в оценку. Вместо одной точности MenuBench
строит **кривую risk–coverage**: сколько ошибок остаётся среди цен, которые система решилась разметить,
при каждом уровне покрытия.

**Статус:** в разработке, см. [план](PLAN.md).

## Что меряется

- **Трек A — извлечение.** На входе картинка или PDF, на выходе `{цена, валюта, название позиции, рамка, уверенность}`.
- **Трек B — привязка к каталогу с отказом.** Привязать каждую цену к каталогу в духе кассы
  (сокращения, опечатки, похожие позиции, позиции, которых нет) — или вернуть подсказку либо отказ с причиной.

Метрики: F1 по ценам и парам, точность названий, ошибка при заданном покрытии, AURC, доля неверных привязок,
$ за меню, задержка p50/p95.

## Конвейер (план)

```
подготовка → VLM-OCR → поиск цен (шаблоны + геометрия) → название позиции (2–3 прохода VLM, большинство)
           → калибровка уверенности → строгий линкер → LLM-арбитр (предлагает, не решает) → привязка | подсказка | отказ
```

Все модели вызываются через [OpenRouter](https://openrouter.ai). Каждый ответ кэшируется локально, поэтому
любой эксперимент можно повторить без сети и бесплатно.

## Данные

Разработка идёт на процедурном генераторе синтетики: HTML-раскладки рендерятся в Playwright, точные рамки
берутся из DOM, сверху — аугментации «под фото». Конвейер замораживается до сбора реальных фото меню, поэтому
реальный сплит — честная отложенная проверка разрыва между синтетикой и реальностью.

## Быстрый старт

```bash
uv sync
uv run menubench --help
uv run pytest
```

Для живых прогонов скопируйте `.env.example` в `.env` и задайте `OPENROUTER_API_KEY`.

## Веб-приложение

```bash
cd web && npm ci && npm run build && cd ..
uv run menubench serve          # http://127.0.0.1:8000
```

- **Runs** — таблица лидеров по всем оценённым прогонам, метрики прогона, кривая risk–coverage, срезы.
- **Разбор меню** — страница с эталоном, предсказаниями по цвету исхода (верно, не та позиция, старая цена,
  нет в меню, пропущено), строками OCR и сырыми ответами каждой стадии конвейера.

Для разработки фронтенда запустите `npm run dev` в `web/` рядом с `menubench serve`; TypeScript-типы API
генерируются из схемы FastAPI (`menubench openapi` → `npm run gen:api`).
