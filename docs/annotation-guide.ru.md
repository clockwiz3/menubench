# Гайд разметки — реальные меню

[← README](../README.ru.md) · [English](annotation-guide.md) · [Карточка датасета](real-dataset.md)

Написан до разметки первого меню и после этого не меняется; если правило всё же меняется, все меню, размеченные по
старому правилу, размечаются заново. Смысл голден-сета в том, что меню №1 и меню №50 размечены по одним правилам.

## Что размечать

**Размечайте только то, что читается уверенно при 100% масштабе.** Никогда не угадывайте цифру: пропущенная цена —
меньшая ошибка, чем неверная, ровно как на экране. Если что-то пропущено из-за блика или размытия, добавьте тег
`partially-unreadable`.

| В меню | Разметка |
|---|---|
| Блюдо или напиток со своей ценой | **позиция** (название) и **цена**, связанная с ней |
| Заголовки разделов («Supe», «Салаты», «Drinks») | ничего — это не позиции |
| Описания, состав, аллергены | ничего — не часть названия |
| Вес или объём порции как информация («300 g», «0,5 l» рядом с единственной ценой) | ничего — не цена и не часть названия |
| Несколько размеров со своими ценами («0,33 l 250 / 0,5 l 350», S/M/L) | одна позиция; по цене на размер, тип **size variant**, подпись размера — как напечатано |
| Комбо или сет («Combo 1: burger + fries + drink 890») | одна позиция с названием как напечатано, одна цена; состав — не отдельные позиции |
| «Цена по запросу», «po dogovoru», «market price» | позиция без цены |
| Позиции без цены, потому что у группы одна цена («все блины 450») | позиция с названием группы как напечатано («Palačinke») и одна цена; перечисленные варианты — не позиции |
| Зачёркнутая старая цена рядом с новой | обе цены; у старой тип **crossed** |
| «od 450», «от 450», «from 450» | тип **from**, значение 450 |
| «450–650» | тип **range**, значение 450, верхняя граница 650 |
| Доплаты («+60 din extra cheese»), залоги, доставка | ничего — это не позиции меню |

## Названия

- Ровно как напечатано: та же письменность (кириллица или латиница), регистр и пунктуация. Не переводить, не
  транслитерировать, не исправлять опечатки.
- Название в несколько строк — одна позиция; рамка охватывает весь блок названия.
- Двуязычные меню (сербский + английский): название — строка на языке меню (выбранном при загрузке), вторая игнорируется.
  Тег `bilingual`.

## Цены

- Значение числом: `1.250` в сербском меню — это **1250** (точка — разделитель тысяч), `1.250,00` — 1250, `12.50` в
  меню в евро или долларах — 12.50.
- Валюта — только если напечатана рядом с ценой или в шапке для всех цен (`din`, `дин`, `RSD` → RSD).
- Рамка цены плотно охватывает напечатанную цену вместе со знаком валюты, если он примыкает; без веса, размеров и
  точек-заполнителей.

## Теги (срезы в отчётах)

Отметьте все подходящие: `printed-pdf`, `photo`, `glare`, `angled`, `low-light`, `chalkboard`, `handwritten`,
`multi-column`, `bilingual`, `cyrillic`, `latin`, `mixed-script`, `laminated`, `sizes`, `combo`, `partially-unreadable`.
Результаты на реальных фото считаются по каждому тегу.

## Порядок работы

1. До загрузки обрежьте или замажьте всё, что не меню: людей, лица, номера машин, чеки.
2. **Annotate** → загрузка (язык сербский) → **Pre-label with pipeline** → поправить каждую рамку, название и связь →
   теги → **Finish**. Finish не пройдёт, пока у какой-то цены нет позиции.
3. Когда все меню закончены, один раз зафиксируйте сплит: `uv run menubench real split --dev 20 --seed 7`. После этого
   тестовые меню не прогоняются, не смотрятся в разборе прогонов и не используются для порогов, пока конвейер не
   заморожен. Команда откажется перераспределять повторно.
4. Через неделю переразметьте пять меню, не глядя на первую разметку: `uv run menubench real recheck <id1>,…,<id5>`
   создаёт пустые копии, разметьте их в Annotate. Затем `uv run menubench real agreement` запишет согласие разметки в
   `reports/annotation_agreement.md`.
